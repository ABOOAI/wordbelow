<h1 align="center">词下 · WordBelow</h1>

<p align="center">读英文，中文在词下。<br>保留英文原文，用小字中文陪你读完一页。</p>

<p align="center"><a href="https://github.com/ABOOAI/wordbelow/releases/latest">下载 Chrome 安装包</a> · <a href="https://abooai.github.io/wordbelow/">中文介绍与交互演示</a> · <a href="#安装">安装说明</a> · <a href="#api-配置">API 配置</a></p>

词下是一款桌面 Chrome 扩展，提供**离线逐词对照**和**API 整句翻译**。中文以较小字号、较细字重显示在对应英文下方，无需点击每个单词。默认由右键启动，也可以开启自动翻译英文网页。中文页面会自动跳过。

当前版本：**1.5.0**。Manifest V3，最低 Chrome 109。源码可直接加载，无需编译；当前通过 GitHub 提供解压加载版本。

## 两种阅读方式

| 模式 | 中文显示位置 | 翻译来源 | 是否需要 API |
| --- | --- | --- | --- |
| 逐词对照（本地） | 每个可处理英文单词下方 | 随扩展打包的 ECDICT 英汉词典和常用词简释 | 不需要，可离线使用 |
| 整句翻译（API） | 对应英文句子下方 | 你配置的 OpenAI 兼容服务；支持 Qwen-MT Flash 专用调用 | 需要自己的服务地址、模型和密钥 |

逐词模式显示词典义项，不根据上下文逐词消歧。整句模式帮助理解句意，也可能出现模型误译。中文介绍页的交互示例采用预先编写的译文，只演示排版，切换示例不会调用 API。

## 功能

- **右键直接翻译**：网页右键菜单一级入口显示“翻译此页”；翻译后变为“恢复原文”。使用面板里选择的模式，无需展开扩展子菜单。
- **自动 / 手动切换**：自动翻译默认关闭。开启后自动处理符合条件的英文网页；全局开关和网站暂停设置仍生效。
- **中文页面自动跳过**：结合页面语言与可见原文判断简繁中文页面，排除本扩展插入的中文。混合语言或很短的页面可能判断有偏差。
- **自定义中文样式**：字号可设为英文字号的 45%—85%；支持任意 RGB 颜色、HEX 输入和 0%—100% 透明度。更改样式即时更新已生成的注释，无需再次调用翻译 API。
- **按阅读位置翻译**：API 模式优先处理可视区域及上下 400 像素的提前量；远处内容接近视口时再提交。已完成译文在内存中缓存，减少重复请求。
- **多句合并与并发**：每批可选 1、4、6、8 句，同时请求数可选 1—4 个。按独立标记核对返回结果，再分配到对应英文句子；边界异常时有限回退到单句。
- **动态网页支持**：启动后继续处理新增可见文字；恢复原文、切换设置或页面语言变化时取消旧任务，防止旧译文插回页面。
- **无需共享密钥**：离线模式无需账号；API 模式使用自己的兼容服务。支持从本机 `.txt` / `.key` 文件导入密钥。

## 安装

1. 从 [Releases](https://github.com/ABOOAI/wordbelow/releases/latest) 下载 **WordBelow-1.5.0.zip**，解压到准备长期保留的文件夹。
2. 在 Chrome 地址栏输入 `chrome://extensions`。
3. 打开右上角的**开发者模式**，点击**加载已解压的扩展程序**。
4. 在解压目录中选择**包含 `manifest.json` 的扩展文件夹**。如果下载的是整个仓库的源码 ZIP，请选择其中的 `extension/` 文件夹。
5. 固定“词下 · WordBelow”图标，刷新已打开的英文网页。
6. 在英文网页上右键，直接选择**翻译此页**。默认使用离线逐词模式。

Chrome 会从这个文件夹读取文件，请保留该目录。ZIP 不能通过双击直接安装；这不是 Chrome 应用商店的一键安装包。

### 已安装 WordWise 版本的原位升级

1. 解压新版安装包，把新版扩展文件夹中的文件复制到**原来加载的扩展文件夹**，覆盖同名文件。
2. 保持原扩展目录的路径不变，在 `chrome://extensions` 对原扩展点击**重新加载**。
3. 确认名称变为“词下 · WordBelow”、版本为 **1.5.0**，然后刷新英文网页。

沿用原目录和原扩展条目，可保留扩展 ID、本地 API 配置、密钥和显示设置。不要先移除原扩展，也不要再加载一份新版；加载到不同路径通常会生成新的扩展 ID，原设置不会自动迁移。

## 日常使用

点击扩展图标，在面板中选择“逐词对照（本地）”或“整句翻译（API）”。手动模式下，刷新网页或导航到新页面后需再次右键翻译。在同一文档中的动态内容更新会继续处理。

开启“自动翻译英文网页”后，扩展会自动按所选模式启动；API 模式可能产生服务费用。右键“恢复原文”会暂停当前文档，页内跳转不会立即重启；刷新或打开新文档后重新遵循自动开关。

“在此网站暂停”按网站 hostname 保存。“启用翻译功能”是全局开关。中文透明度 0% 表示完全可见，100% 表示完全透明，但仍保留注释占用的布局。

## API 配置

1. 点击扩展图标，打开 **API 设置**。
2. 填写服务地址、服务商给出的模型名称以及自己的 API 密钥。支持服务根地址、`/v1` 地址或完整 `/chat/completions` 地址。
3. 点击**保存设置**，按 Chrome 提示允许访问所填 API 域名。保存设置不会自动切换翻译模式。
4. 点击**测试翻译**。此操作会向配置的服务发送一条示例句子，可能产生费用。
5. 返回扩展面板选择**整句翻译（API）**，再在英文网页上右键选择**翻译此页**。

远程服务需使用 HTTPS；`localhost`、`127.0.0.1`、`[::1]` 的本机服务允许 HTTP。无需密钥的本机服务可留空密钥。兼容协议服务的模型、消息格式和返回行为仍可能不同；批次输出不兼容时可设为每批 1 句。

### Qwen-MT Flash

点击“使用 Qwen-MT Flash 预设”，使用模型 **`qwen-mt-flash`**，从**每批 4 句、同时 2 个请求**开始。填写你的百炼控制台提供的服务地址和同地域有效密钥，然后保存并测试。公共版本没有内置私人业务空间地址或共享密钥。

扩展按 English → Chinese 使用 Qwen-MT 专用参数，发送一个 user 消息；流式结果完整接收并核对对应关系后，逐句显示在原文下方。多句合并是客户端策略，并非服务商原生批量 API。

若短句较多且服务稳定，可先尝试 **6 × 2**，再尝试 **6 × 3**。出现限流、超时或等待变长时，先降至 **4 × 1—2**；服务不保留批次标记时可选 **1 句**。提高并发不会改善模型语义质量，也不保证整页更快。网络、文本长度、账户配额和服务负载都会影响速度。

Qwen-MT 每批原文上限为 3,600 字符，其他兼容模型为 6,000 字符；实际请求可能少于设定句数。单次网络请求期限为 60 秒，含排队及重试的总期限为 180 秒；超时和 HTTP 429 至多重试一次。失败时保留英文，并显示错误提示。

“关闭 MiMo 深度思考”仅对识别出的 MiMo V2 模型发送专用参数，不会为 Qwen-MT 或其他模型添加该参数。

官方说明：[Qwen-MT 机器翻译](https://help.aliyun.com/zh/model-studio/machine-translation/) · [百炼 OpenAI 兼容接口](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions/)

## 隐私与权限

- **离线逐词模式**在本机查词，不发送网页文字，也不调用外部翻译服务。
- **API 整句模式**把需要翻译的英文句子及翻译参数发送给你配置的服务商，密钥用于该服务的请求授权。服务方的数据处理、计费和保留政策请查看其说明。
- 密钥保存在当前 Chrome 配置的本地扩展存储中，不同步到 Chrome 云端，不写入网页 DOM，也不包含在本仓库或安装包中。本地存储不是加密的密码保险箱。
- 扩展使用 `storage`、`activeTab`、`contextMenus` 权限，并在保存 API 配置时请求所填服务域名的访问权限。内容脚本运行于普通 HTTP/HTTPS 页面，以读取和插入对照文字。
- 本项目没有内置遥测、广告或账号系统。介绍页使用本地资源和静态示例，不会自动提交翻译请求。
- 关闭翻译或切换页面会取消本地旧任务；已发送的请求仍可能由服务商处理并计费。

## 适用范围与限制

适用于桌面 Chrome 的普通 HTTP/HTTPS 网页。代码块、输入框、按钮、可编辑区域和 `translate=no` 内容会跳过。`chrome://` 页面、Chrome 应用商店、浏览器内 PDF 阅读器、图片文字以及 Chrome 手机版不支持。

小字注释会增加行高，长词义可能影响单词宽度；排版密集的页面可以调小中文字号或暂停该网站。离线词典可能缺少专有名词，也可能与上下文词义不同；API 分句可能受缩写、混合语言或异常网页结构影响。批次核对保障对应关系，不能保证译文的全部语义正确。

缓存位于页面和扩展后台内存中。更换 API 配置、后台重启或浏览器重启后可能重新请求。若调用超时，可检查服务地址、网络和模型状态，降低并发后恢复原文，再重新翻译。

## 源码与开发

```text
extension/          Chrome 扩展源码，可直接解压加载
  manifest.json     Manifest V3 配置
  background.js     API 调度、缓存、设置及右键菜单
  content.js        网页处理及逐词排版
  sentence.js       整句排版、视口优先及提前量
  dictionary/       ECDICT 本地分片、元数据及许可
  tools/            词典构建工具
docs/               中文介绍页与本地交互示例
```

扩展无需 Node.js 或编译即可运行。介绍页同样是静态 HTML/CSS/JavaScript。重新生成词典需要 Python；构建方式、固定源版本和分片校验见 [词典说明](extension/dictionary/README.md)。
