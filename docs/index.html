词典常用义，可能与当前语境不同
02 / SENTENCES

整句翻译，理解上下文

接入自己的 OpenAI 兼容 API，或使用 Qwen-MT Flash。返回结果核对后，中文译文放在对应英文句子下方。

服务按各自规则计费，模型仍可能误译
03 / ON YOUR TERMS

右键即翻译，也可自动

默认手动：右键直接点“翻译此页”，再点“恢复原文”即可关闭。需要随时伴读，可以开启自动翻译英文网页。

简体、繁体中文页面自动跳过
04 / A LITTLE AHEAD

读到哪里，译到附近

API 模式优先提交可视区域和上下 400 像素的提前量。远处未浏览内容接近后再译，完成结果复用缓存。

减少未读内容的提交与重复调用
05 / YOUR COLORS

小字的颜色，由你决定

中文字号、任意 RGB 颜色、HEX 色值、透明度都可自定义。调样式即时生效，英文样式照旧，无需重新请求译文。

离线逐词和 API 整句都支持
06 / KEEP IN CONTROL

给每个网站一个选择

单独暂停当前网站，或用总开关关闭翻译。恢复原文会移除注释、停止旧任务；启动后继续处理新加载内容。

代码、输入框和可编辑区域会跳过

几步安装，

源码可直接运行，无需构建。首次安装使用 Chrome 的“加载已解压的扩展程序”。

下载 v1.5.0 ↓
  1. 1

    下载并解压

    将安装包解压到固定文件夹，并保留这个目录。找到其中包含 manifest.json 的扩展文件夹。

  2. 2

    加载到 Chrome

    打开 chrome://extensions，开启“开发者模式”，点击“加载已解压的扩展程序”，选择刚才的扩展文件夹。

  3. 3

    刷新网页，右键翻译

    固定“词下”图标，刷新英文网页，右键直接选择“翻译此页”。默认从离线逐词开始；API 模式需先配置服务。

已经安装旧版 WordWise？

用新版文件覆盖原加载目录，保持路径不变，在扩展管理页点击原卡片的“重新加载”，再刷新网页。这样可保留扩展 ID、API 密钥和设置。请保留原扩展条目。

BRING YOUR OWN API

接入熟悉的模型，
按句读懂英文。

打开扩展面板中的“API 设置”，填写服务地址、模型和自己的密钥，保存并允许访问该域名。测试成功后，选择整句模式，再右键翻译网页。

密钥只保存在当前 Chrome 的本地扩展存储中，不会交给网页。API 模式会向所配置的服务发送待译英文，请按服务商政策选择使用内容。

A FEW THINGS TO KNOW

使用前，了解这些。

逐词模式真的会给每个英文词加中文吗？+

启用后会自动处理可见正文中的英文单词，无需逐个点击。词典未收录的单词可显示“未收录”；代码、输入框、按钮、可编辑区域和网页设置为不翻译的内容会跳过。词典释义不一定符合当前句子中的词义。

安装后没有看到翻译，怎么办？+

默认不会自动翻译。先刷新英文网页，确认总开关已开启、当前网站未暂停，再右键选择“翻译此页”。中文页面会自动跳过。API 模式还需先保存服务配置并测试成功。

API 很慢或超时，可以怎么调？+

Qwen-MT Flash 推荐从每批 4 句、同时 2 个请求开始。限流或等待增加时降到 1—2 个并发，批次格式不兼容时设为每批 1 句。网络、文本长度、模型负载与配额都会影响速度；单次请求期限 60 秒，失败后保留英文。恢复原文后重新翻译可以重试。

网页内容和密钥会发到哪里？+

离线模式完全在本机查词，不发送网页文字。API 模式向你配置的服务发送英文句子和翻译参数，密钥仅用于服务授权；项目没有自建翻译中转服务。密钥保存在本机扩展存储中，不写进网页、安装包或本仓库；本地存储不是加密的密码保险箱。具体数据处理与计费由服务方决定。

哪些页面暂时不支持？+

Chrome 内置页、应用商店、浏览器 PDF 阅读器、图片里的文字和 Chrome 手机版不支持。密集排版可能因小字注释增加行高；可降低字号或暂停该网站。分句与中文识别采用有限文本判断，混合语言、缩写或异常结构可能影响结果。

这个项目从哪里来，能修改源码吗？+

词下基于 breeze-r/wordwise 改造，词典来自 skywind3000/ECDICT，均保留 MIT 许可和来源。新增源码同样以 MIT 许可提供，扩展无需编译，可在 GitHub 查看、修改和分发。本项目与第三方“沉浸式翻译 / Immersive Translate”产品无隶属关系。
