词下 · WordBelow 1.5.0
英文在上，中文在下。保留原文的沉浸式双语阅读扩展。

Chrome 安装
1. 下载 WordBelow-1.5.0.zip，解压到一个固定文件夹。
2. 在 Chrome 打开 chrome://extensions/，开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 manifest.json 的文件夹。
4. 打开并刷新一个英文网页，右键直接选择“翻译此页”。
5. 再次右键选择“恢复原文”，可移除本页中文标注。

此包是可加载的 Manifest V3 扩展，不需要编译。
Chrome 最低版本为 109。不提供需要浏览器外部安装授权的 CRX。
GitHub 源码安装时，选择仓库内的 extension 文件夹。

两种模式
• 逐词对照（本地）：每个已收录英文词下方显示小字中文释义，无需账号或联网。
  自带 ECDICT 词典，398,070 个查找键，另有 164 个常用词的简释。
  释义来自词典，不根据整句上下文消歧；未收录的词不会猜译。
• 整句翻译（API）：在每句英文下方显示中文小字，使用你自己的 OpenAI 兼容服务。
  支持 Qwen-MT Flash 专用翻译参数，也支持其他兼容 Chat Completions 的模型。
  模型译文的准确性取决于提供商和文本；有歧义的内容仍需结合原文判断。

开始与停止
默认关闭“自动翻译英文网页”，由网页右键菜单启动当前页。
扩展弹窗可开启自动翻译，也可关闭总开关或“在此网站暂停”。
以中文为主的页面自动跳过；检测依据页面语言及可见内容，混合语言页面可能存在边界情况。
浏览器内部页面、Chrome 商店、内置 PDF 阅读器、图片文字不属于普通网页文本支持范围。
代码、输入框、可编辑区域及明确禁止翻译的内容会跳过。

中文样式
在扩展弹窗中调整字号、选择预设或任意 HEX 颜色、设置 0–100% 透明度。
0% 完全不透明，100% 完全透明。仅改变中文，不改变英文原文。
样式修改会更新已出现的标注，不会为了改变颜色重新调用 API。

API 设置
1. 在扩展弹窗选择“API 设置”。
2. 填写服务提供商给出的 HTTPS 服务地址、模型名称和自己的 API 密钥。
   可使用服务根地址、/v1 地址或完整 /chat/completions 地址。
   本机服务支持 http://localhost、127.0.0.1 和 [::1]，本机密钥可留空。
3. 也可从包含一条纯密钥或单行 API_KEY 配置的 .txt/.key 文件导入密钥草稿。
4. 点击“保存设置”，按 Chrome 提示允许访问该 API 服务域名。
5. 点击“测试翻译”，成功后在弹窗中选择“整句翻译（API）”。
6. 回到英文网页，通过右键启动，或开启自动翻译。

Qwen-MT Flash
点击“使用 Qwen-MT Flash 预设”会填入 qwen-mt-flash、每批 4 句、同时 2 个请求。
预设保留有效的非 MiMo 服务地址；从 MiMo 切换时需填写自己的百炼或兼容网关地址。
已是 Qwen-MT 的地址与密钥草稿可保留；切换服务时需使用新服务对应的密钥。
预设只修改表单草稿，保存前不会改变原配置或发送请求。
请从百炼控制台复制当前业务空间和地域对应的地址，并使用同地域密钥。
本公开包不含个人业务空间地址、API 密钥或预付额度。
官方说明：https://help.aliyun.com/zh/model-studio/machine-translation/

翻译速度与费用
API 翻译优先处理当前可见区域，以及上下约 400 像素的提前量。
远处内容在滚动接近后提交；仍会根据句子所在区块和长度拆分请求。
批量返回后按句子对应关系插回网页。边界异常时回退到单句核对。
近期翻译结果缓存可避免短期重复提交；取消翻译后停止待处理任务。
Qwen-MT 建议从 4 句 × 2 个请求开始；通用模型默认 6 句 × 3 个请求。
出现限流、超时或等待变长时，先将同时请求数降到 1–2，再减少每批句数。
并发和批次上限取决于服务商额度与模型速度，不保证任何固定时间内翻完一页。
批量是本扩展合并多句的兼容调用，不是服务商离线 Batch API。
MiMo V2 可选择关闭思考；此开关不向 Qwen-MT 发送 MiMo 参数。

数据与权限
离线逐词模式在本机查词，不向翻译接口发送页面内容。
API 模式向你配置的服务发送需要翻译的句子，并用你的密钥授权；可能产生费用。
密钥保存在本机 Chrome 扩展存储，不提供给页面内容脚本，也不随源码或安装包附带。
扩展无自建账号、遥测或云端同步服务。服务提供商自身的数据处理规则需自行了解。
扩展使用 storage、activeTab、contextMenus；保存 API 地址时按需申请该域名权限。

现有安装升级
如原扩展已经通过“加载已解压的扩展程序”安装：
先退出正在查看的扩展弹窗，将新包文件覆盖到原安装目录，再点击原卡片的“重新加载”。
刷新网页即可使用新名称与图标。不要先移除原扩展或另选新路径，以免更换扩展 ID。
本版本保留旧 wwInterlinearSettings / wwInterlinearApiConfig 存储键，兼容既有设置。
更新包不会主动迁移、清空或上传你的 API 配置。
